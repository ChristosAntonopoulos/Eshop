# Eshop — LCG Shop Frontend

Fitness / sports supplement storefront (**LCG Shop**, near OAKA / Marousi).

## Projects

| Folder | Description |
|--------|-------------|
| [`lcg-shop-frontend/`](lcg-shop-frontend/) | React + TypeScript + Vite SPA |

## Quick start

```bash
cd lcg-shop-frontend
npm install
npm run dev
```
